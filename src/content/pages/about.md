I'm a tech enthusiast — my hobbies are ham radio, homelabbing, and Python development.

Over time that homelabbing hobby has grown into a real self-hosted infrastructure: a Proxmox server running
a dozen-plus virtual machines, each dedicated to a different group of services — media, DNS, chat, community
sites, and more — all reverse-proxied, monitored, and documented like it's production, because to the people
who use it, it is.

This blog exists to document the progress of my homelab: what I've built, how it's put together, the
decisions behind it, and the troubleshooting that comes with running it all myself. It doubles as a running
record of hands-on infrastructure and software work — the kind of thing a resume can only summarize in a
line or two.
